# MEU RUMO — gerar APK sem Android Studio

## 1. Criar o repositório
No GitHub, crie um repositório vazio chamado `MeuRumo`.

## 2. Enviar os arquivos
Envie todo o conteúdo desta pasta para o repositório, mantendo a pasta `.github/workflows`.

## 3. Compilar
No GitHub, abra **Actions** → **Build MEU RUMO APK** → **Run workflow**.

O GitHub vai compilar o projeto e publicar um artefato chamado **MeuRumo-debug-apk**.

## 4. Baixar no A15
Baixe o artefato, extraia o ZIP e abra `app-debug.apk` no Galaxy A15 para instalar.

Observação: este é um APK de debug para testes. A integração de passos depende do Health Connect e das permissões do aparelho.
